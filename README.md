# Customer Sales Trend Analysis

## Files
- `Customer_Sales_Trend_Analysis.ipynb` — analysis notebook
- `ecommerce_sales_generated.csv` — generated practice dataset
- `Business_Brief.md` — one-page business summary

## Run
1. Keep the notebook and CSV in the same folder.
2. Install dependencies: `pip install pandas numpy matplotlib seaborn jupyter`
3. Open the notebook in Jupyter or VS Code.
4. Run all cells from top to bottom.

## Data disclosure
The CSV is generated synthetic data. It contains no real customer information.
